# Example applications

The four applications bundled with CASA, in increasing order of complexity.

* [Barebones example](barebones.md) - The smallest viable CASA application.
* [DWP Frontend example](dwp-frontend.md) - Barebones integrated with the @dwp/dwp-frontend design system.
* [Multiapp example](multiapp.md) - Multiple CASA sub-apps within one parent ExpressJS application.
* [Fully-loaded example](fully-loaded.md) - Exercises every CASA feature; basis for the e2e test suite.
