# References

External standards and libraries that CASA builds on, mirrored here as
first-class concepts.

* [GOV.UK Design System](govuk-design-system.md) - The component and pattern library CASA forms adopt.
* [govuk-frontend](govuk-frontend.md) - The npm package implementing the Design System.
* [ExpressJS](express.md) - The Node.js web framework CASA is built on.
* [i18next](i18next.md) - The library powering CASA's translations.
* [Nunjucks](nunjucks.md) - The templating engine CASA renders pages with.
