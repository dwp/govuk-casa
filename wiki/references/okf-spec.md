This wiki targets OKF v0.1. The bundle uses markdown files with YAML
frontmatter for concepts, `index.md` files for progressive disclosure, and a
root `log.md` for update history.

# Local conventions

* The bundle root is `/wiki`.
* Concept documents live under `/concepts`, `/examples`, `/playbooks`, and
  `/references`.
* Bundle-relative links start with `/`.
* The root `index.md` declares `okf_version: "0.1"`.
